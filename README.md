# is-115-gruppe3-studenthub

## Bruke

1: Lag en fil med navnet `config.php`.
2. Kopier innholdet i `config.example.php` og plasser det i `config.php`.
3. Endre variabler i `config.php` slik at det passer systemet ditt.
4. Sørg for at det finnes en database med navnet du har spesifisert i `config.php`.
5. Åpne phpmyadmin og kjør `database.sql` på databasen.
